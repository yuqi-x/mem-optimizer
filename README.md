# MemOptimizer

Windows 内存优化小工具，一个 .pyw 文件，双击就能跑。

跟那种"一键释放 10GB"的清理软件不太一样：它不逐个进程去调 EmptyWorkingSet，而是直接把指令交给内核，让内核自己把该清的清掉。所以整个过程十几秒，CPU 基本不动。

## 怎么用

双击 `启动内存优化.bat`（或者直接双击 `MemOptimizer.pyw`），弹一次 UAC，允许就行。

窗口里默认勾着三项，点「开始优化」，完事。

不想开窗口：

```
python MemOptimizer.pyw --cli
```

## 它到底干了啥

关键 API 是 `ntdll!NtSetSystemInformation`，第一个参数固定传 80，第二个参数决定干什么：

| 值 | 内核动作 | 说明 |
|---|---|---|
| 2 | MemoryEmptyWorkingSets | 清空所有进程的工作集 |
| 3 | MemoryFlushModifiedList | 把「已修改页」刷回磁盘 |
| 4 | MemoryPurgeStandbyList | 清空备用内存列表 —— **数字真正掉下来的就是这步** |
| 5 | 低优先级备用列表 | 可选 |
| 81 | 系统文件缓存 | 可选 |
| 155 | 注册表缓存 | 可选 |
| 130 | 合并物理内存 | 可选，多数系统直接返回不支持，正常 |

调之前得先拿到 `SeProfileSingleProcessPrivilege`，没这个特权内核压根不理你。

前三个是默认勾选的，第四组四个默认不勾 —— 不是不能用，是副作用比前面三个大，想看效果自己开。

第 4 步是耗时大头，内存压力大的时候十几秒很正常，别以为卡死了。

## 实测

我自己这台机器，16G 内存，跑了一天多没重启：

```
可用内存   4.07 GB  ->  6.29 GB    (+2.22 GB)
占用率     74%      ->  60%
耗时       12.1 秒
```

三项内核指令全部返回成功。

## 几句实话

- **这不是白赚的。** 备用列表和文件缓存里存的是系统辛苦攒下来的热数据，清掉之后要用还得重新从磁盘读，短期内打开很久没碰的程序可能会慢那么一下。属于正常代价，不是 bug。
- 内存本来就空的话跑它，数字基本不动 —— 不代表失败，说明本来就不缺。
- 治标不治本。内存长期吃紧该加条子就加条子，该关的软件就关软件，这东西只是应急腾个地方。
- 只对 Windows 有效，而且必须要管理员权限，否则特权拿不到。

## 环境

Python 3.8+，只用标准库（ctypes + tkinter），零第三方依赖。
